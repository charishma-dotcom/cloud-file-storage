CLOUD FILE STORAGE

1. About the Project
Cloud File Storage is a simple web application that allows users to store and manage their files in one place.
Users can upload files, create folders, organize their files, share files with other users, and manage deleted files.
The application is designed to make file management simple, organized, and secure.

2. Main Features
User registration and login
Upload and download files
Create folders and subfolders
Organize files inside folders
Open and view files
Search for files
Mark important files as starred
Share files with other users
Give Viewer or Editor permissions
Create public links for files
Protect public links with passwords
Set expiry dates for public links
Move deleted files to Trash
Restore files from Trash
Permanently delete files
View recently opened files
Manage shared files

4. How It Works
I. The user creates an account and logs into the application.
II. The user can create folders and upload files.
III. Files can be organized inside different folders.
IV. Users can open and download their files whenever required.
V. Important files can be marked as starred for quick access.

4. Technologies Used
Java 17
Spring Boot
Spring Security
JWT Authentication
Spring Data JPA
PostgreSQL
Maven
React
Vite

6. Project Purpose
The main purpose of this project is to provide an easy and secure way for users to store, organize, access, and share their files.
The project provides user authentication, file management, folder management, file sharing, public sharing, search, starred files, and Trash management.
The system also controls user access based on the permissions given by the file owner.
